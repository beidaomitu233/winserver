   Context

   WinServer is a Windows web development environment manager (Nginx + PHP). Phase 1 was a
  Node.js web panel. Phase 2
   migrates to Tauri 2 + Vue 3 + Rust Agent architecture. The Rust backend and Tauri command

 - frontend/src/pages/DashboardPage.vue — Wire "Ports" quick-action to open PortCheckModal.
 - frontend/src/pages/SettingsPage.vue — Add "Check Port" button in Network section.

}).
 - frontend/src/stores/useServiceStore.ts — Add configFiles ref populated from

 - frontend/src/pages/SettingsPage.vue — Add config file list with "Edit" buttons in Network
section.
 - Wire DashboardPage service "Config" button and SitesPage "Config" button to open this modal.

 WP8: Settings Network/Security/Backup Sections

 - frontend/src/pages/SettingsPage.vue — Replace three placeholder sections with real forms:
   - Network: Default HTTP port input, phpMyAdmin URL, config file list (WP7 integration)
   - Security: MySQL root password change (calls db_root_password), hosts write permission
check
   - Backup: Data directory path with "Open" button, "Export/Import Settings" buttons, database
 backup list
 - frontend/src/stores/useSettingsStore.ts — Extend to support new settings fields and path
updates.
 - frontend/src/types/index.ts — Extend SystemSettings with network/security/backup fields.

 WP9: Site Enable/Disable

 - agent/src/managers/site_manager.rs — Add enable_site (write vhost + sync hosts + validate +
reload + health check)
 and disable_site (remove vhost + remove hosts + validate + reload). Follow existing rollback
patterns.
 - agent/src/server/handler.rs — Add site.enable and site.disable RPC handlers.
 - frontend/src-tauri/src/commands.rs — Add site_enable, site_disable Tauri commands.
 - frontend/src-tauri/src/lib.rs — Register new commands.
 - frontend/src/pages/SitesPage.vue — Add enable/disable toggle per site row, dim disabled
rows.
 - frontend/src/stores/useSiteStore.ts — Add enableSite, disableSite methods.

 WP10: Background Health Monitoring

 - agent/src/managers/process_manager.rs — Add start_health_monitor() that spawns a tokio task
checking tracked PIDs
 every 5s. When a PID dies unexpectedly, update DB state to Failed with error message and log
the event.
 - frontend/src-tauri/src/app_state.rs — Call start_health_monitor() during initialization.

 WP11: Dashboard Fixups

 - frontend/src/pages/DashboardPage.vue — Fix database KPI (use
databaseStore.databases.length), replace <router-link>
 with @click="currentPage = 'xxx'", wire all quick-action buttons, wire service "Config" button
 to ConfigEditorModal.
 - Depends on WP6 (port check) and WP7 (config editor) for full wiring.

 WP12: Code Cleanup

 - Delete unused model stubs: agent/src/models/service.rs, site.rs, runtime.rs. Update mod.rs.
 - Remove duplicate generate_vhost_config from agent/src/adapters/nginx.rs (SiteManager's
Handlebars template is
 canonical).
 - Remove agent/src/adapters/php_fastcgi.rs (ProcessManager handles PHP-CGI lifecycle). Update
adapters/mod.rs.
